מדיניות פרטיות

עודכן לאחרונה: 18 באוקטובר 2026

OrdoX היא אפליקציה פרטית לניהול לימודים, שמשמשת את המפתח בלבד. היא לא מוצעת לציבור.

מידע שהאפליקציה ניגשת אליו

  • חשבון Google: כתובת אימייל, שם ומזהה, לצורך התחברות.
  • Google Calendar: קריאת אירועים מהיומנים שהמשתמש בוחר, ויצירה ועדכון של אירועים ביומן נפרד בשם "OrdoX – לימודים".
  • Google Drive: יצירה, קריאה וארגון של קבצים בתיקיית OrdoX של המשתמש.

איך המידע נשמר

  • אירועי היומן נשמרים במטמון במכשירי המשתמש בלבד.
  • תוכן הקבצים נשאר ב-Google Drive של המשתמש.
  • נתוני הלימוד (קורסים, משימות, הערות, כרטיסיות) והטקסט שחולץ מקבצים נשמרים במסד נתונים פרטי (Supabase, אירופה), שרק המשתמש עצמו יכול לגשת אליו, ומסונכרנים בין מכשיריו.
  • אסימוני הגישה של Google נשמרים רק באחסון המוצפן של מכשירי המשתמש.

עיבוד בבינה מלאכותית

לפי בקשת המשתמש, עמודים מקבצים נשלחים ל-Anthropic (Claude) לזיהוי כתב יד וליצירת כרטיסיות חזרה, וקטעי טקסט נשלחים ל-Voyage AI לחישוב חיפוש סמנטי. הנתונים לא משמשים לאימון מודלים.

שיתוף

המידע לא נמכר, לא משותף ולא משמש לפרסום. השימוש במידע שמתקבל מ-Google APIs עומד ב-Google API Services User Data Policy, כולל דרישות ה-Limited Use.

מחיקה

אפשר לבטל את הגישה בכל עת בכתובת myaccount.google.com/permissions ולמחוק את הנתונים מתוך האפליקציה.

Privacy Policy

Last updated: October 18, 2026

OrdoX is a private study-management app used only by its developer. It is not offered to the public.

Data accessed

  • Google account: email, name and ID, for sign-in.
  • Google Calendar: reads events from calendars the user selects; creates and updates events in a dedicated "OrdoX" calendar.
  • Google Drive: creates, reads and organizes files in the user's OrdoX folder.

Storage

Calendar events are cached on the user's devices only. File contents stay in the user's Google Drive. Study data and text extracted from files are stored in a private database (Supabase, EU) accessible only to the user, and synced between the user's devices. Google tokens are kept only in the devices' encrypted storage.

AI processing

At the user's request, file pages are sent to Anthropic (Claude) for handwriting recognition and flashcard generation, and text passages to Voyage AI for semantic search. This data is not used to train models.

Sharing

Data is never sold, shared, or used for advertising. OrdoX's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deletion

Access can be revoked at any time at myaccount.google.com/permissions, and data can be deleted from within the app.
